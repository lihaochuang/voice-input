# 固定纠错表（示例）：ASR 老听错的词，在这里写死「错 => 对」。
#
# 首次运行时程序会把这个文件复制成「纠错表.txt」，之后你编辑那一份。
# 格式：错的写法 => 对的写法     （一行一条，# 开头是注释）
# 改完存盘即生效，不用重启。
#
# ⚠ 下面的示例默认全部注释掉了，故意的。
#
# 纠错表是「用规则掩盖识别错误」。开早了有个坏处：你会以为识别准了，
# 其实是替换出来的，于是永远不知道 ASR 真正的错误率在哪。
#
# 什么时候才该开一条：
#   1. 这个词你反复遇到，确认是误识别而不是你真说了它
#   2. 业务里压根没有那个错的说法（不可能是另一个意思）
# 两条都满足，再把对应行前面的 # 去掉。
#
# 先试热词表：把专有名词加进「热词.txt」通常就不错了，
# 那是让模型认得这个词，比事后替换更干净。
#
# 格式示例（把前面的 # 去掉就生效）：
# 留存绿 => 留存率
# 幂等姓 => 幂等性
# 并法 => 并发
