# 热词表（示例）
#
# 首次运行时程序会把这个文件复制成「热词.txt」，之后你编辑那一份。
# 一行可写多个词，空格分隔，# 开头是注释。改完存盘即生效，不用重启。
#
# 作用：这些词会随每次语音请求发给 ASR 模型做识别偏置。
#      专有名词加进来就基本不会错了——通用模型没见过你的行业术语，加了才认得。
#
# ⚠️ 注意：热词表的内容会发送到你配置的 ASR 服务。
#         别往里写密码、密钥、金额、身份证号这类敏感信息。
#
# ⚠️ 别贪多：几百个精选词效果最好。表太长会稀释每个词的权重，
#         而且把 ASR 本来就认得的通用词（「数据」「问题」「时间」）加进来没有收益。
#
# 不用手动一个个加：用一段时间后打开「设置 → 热词 → 挖掘候选」，
# 它会从你的历史记录里挖出高频词，你勾选确认后一键并入。

# ── 下面按你自己的领域替换掉 ──
